# NAME

NAME stands for whatever you call this system: set it once with `python scripts\overlay.py name <Name>`, then type `/<name>` (or `/NAME`, which still works).

NAME keeps your six running 1:1 documents and one Action Register straight, so you're not holding all of it in your head or opening six Docs to check what's still open. Phase 1 only, for now: no email goes out, no calendar changes happen, no transcript gets read. Just your running Docs and what you owe each other.

## The five commands

| Command | What it does |
| --- | --- |
| `/NAME <request>` | The general front door. Say what you need in your own words, NAME works out which of the team handles it. |
| `/add <text>` | Capture a topic or a commitment the moment you think of it. Goes straight into the right person's running Doc and the register. |
| `/owe [person]` | What you still owe, by person or everyone at once. Add `history <ref>` to see how many times something's moved. |
| `/morning` | Your first check of the day, chat only. Is NAME actually running, what's due or overdue, what's still unanswered. |
| `/boi` | NAME already suggested something and you agree. Say it instead of repeating yourself, it does the specific thing it just proposed. |

## What it takes off your plate

- Six running Docs in one place. No more opening each one just to check what's open.
- Commitments caught as you say them. "I'll send Casey the bonus structure Friday" becomes a tracked action the moment you say it, not something you remember to write down later.
- Completion that works both ways. Mark it done in chat, or type Done in its Status cell yourself, either one closes the loop.
- History you shouldn't have to hold yourself. How many times something's moved, what's still open with each person, on request.

A switched-off agent costs nothing to ask for, it answers instantly with what it needs to switch on.

## Nothing goes out without you (not yet, anyway)

NAME is allowed to write today, unlike a system that only ever proposes and waits. Give it a clear command, not "should I add this?", and it writes a topic or a commitment straight into the right person's running Doc, in the Next 1:1 section, then shows you exactly what it wrote before calling the job done.

That's the only kind of write it does. No email goes out, from you or on your behalf. Calendar is read only, just enough to know when someone's next meeting actually is. No transcript gets read. Those switch on in later phases, each one only after you've seen the one before it run clean, and only once you tell it to.
